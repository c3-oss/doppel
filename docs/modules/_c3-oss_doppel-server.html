    @c3-oss/doppel-server - Daemon and API server for Doppel

    @c3-oss/doppel-server publishes the doppel-server binary and server library. It runs the Doppel daemon, exposes HTTP/tRPC and WebSocket surfaces, serves the single-session browser terminal view, and can host the administrative web UI.

    Install

    npm install -g @c3-oss/doppel-server

    Run through npx by binary name:

    npx doppel-server start --daemon

    Quickstart

    Start the daemon:

    doppel-server start --daemon

    Check status:

    doppel-server status
    doppel-server status --json

    Serve the administrative web UI:

    doppel-server start --web-ui

    Stop the daemon:

    doppel-server stop

    Runtime

    By default, the daemon binds to port 3000 and exposes:

    • /health
    • /trpc
    • /ws/terminal/:sessionName
    • /session-view

    The administrative web UI binds to port 3001 when enabled and talks to the daemon at http://localhost:3000.

    Useful options:

    doppel-server start --host 127.0.0.1 --port 3000
    doppel-server start --web-ui --web-ui-port 3001
    doppel-server start --json-logs
    doppel-server start --no-logger

    Library API

    import {
      createServer,
      startServer,
      type AppRouter,
    } from '@c3-oss/doppel-server';

    Use @c3-oss/doppel-core directly when you want the terminal and schedule engine without the HTTP server.
